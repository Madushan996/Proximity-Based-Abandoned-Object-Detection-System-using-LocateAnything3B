PADS

Proximity-Based Abandoned Object Detection System — Pipeline Flow
Input
📷 Video Feed
File (.mp4) · Webcam · IP Camera (RTSP)
M1 — Runs Once at Startup
Scene Initialisation
Warm up MOG2 over first 30 frames
Detect all existing objects → mark pre_existing = true
These are never flagged as abandoned
↻ Per-Frame Loop — runs on every frame
M3
Person Detection & Tracking
YOLOv8n detects all persons
ByteTrack assigns persistent IDs
Records foot-point (bottom-centre)
⟵ runs first ⟶
M2
Foreground Detection
MOG2 background subtraction
Morphological clean-up
Person-overlap filter → skip person blobs
Register new object blobs
M4
Coordinate Mapping
Pixel (px, py) → World (metres)
Flat scale or full Homography (H matrix) for perspective correction
All distances from here on are in real-world metres
M5 — Event-Driven (fires on new object)
Proximity Association Engine
New object detected → find nearest in-frame person
If distance ≤ R (1.5m) → lock association (object_id ↔ person_id)
If distance > R → pending queue, retry for T_pending (10s)
Tiebreak: closest wins · if tied, longer dwell time wins
NEW → ASSOCIATED or PENDING
M6 — Every Frame
Separation Monitor
Compute sliding-window avg distance (person ↔ object) over last T_window (1s)
If avg dist > D (2.0m) continuously for > T_grace (4s) → SEPARATION EVENT
If person returns within R before T_grace → cancel, reset to ASSOCIATED
ASSOCIATED → OF INTEREST
M7 — Continuous
Alarm & Event Manager
Watch for person-of-interest exiting frame → start T_abandon (120s) countdown
During countdown: check if anyone retrieves the object
If object retrieved → CANCEL alarm
If T_abandon expires with no retrieval → DISPATCH ALARM
OF INTEREST → RETRIEVED or ALARMED
